## ✨ למה זה קיים

- רואים ריל וחושבים "איך עשו את המעבר הזה?", בלי לדעת איך קוראים לו ואיך בונים אותו.
- מדריכים ארוכים, ושמות האפקטים משתנים בין תוכנות.
- נותנים את הסרטון ל-Claude Code ומקבלים **זמנים, תיאור, ראיות מהפריימים ומתכון מעשי**, ושומרים הכול בספרייה שאפשר לחפש בה ושגדלה איתך.

זו **ספריית ידע, לא תוכנת רינדור**. כלי העריכה שלך (HyperFrames, Remotion, FFmpeg, After Effects…) מבצע את הרינדור, והפרויקט אומר לו *מה* לבנות ו*איך*.

## 🚀 התחלה מהירה

</div>

```bash
git clone https://github.com/moshspro-dev/video-effect-reel.git
cd video-effect-reel

./reel-effects lang he                      # עברית (אפשר גם לדלג)
./reel-effects find "רמפת מהירות"           # עובד מיד, בלי התקנות
./setup.sh                                  # פעם אחת: Pillow ו-yt-dlp לניתוח סרטונים
./reel-effects add ~/Videos/reference.mp4   # ניתוח סרטון (דורש FFmpeg ו-Claude Code)
.venv/bin/python web_server.py              # דף נוח לטלפון ב-http://127.0.0.1:4319/
```

<div dir="rtl" align="right">

הפקודה `find` מחפשת מילים בעברית ובאנגלית יחד. עם `--lang he` המתכון מודפס בעברית, ועם `--json` אפשר להעביר אותו לסקריפט או לסוכן.

## 🔒 פרטי מהיסוד

- הספרייה המשותפת (`library/`) כוללת **רק מתכונים כלליים**, לא סרטונים של אף אחד.
- **הניתוחים שלך והקישורים שניתחת נשארים בתיקייה `local/`**, ש-Git מתעלם ממנה. אפשר למשוך עדכונים ולתרום בלי לפרסם מה למדת.
- הכלי לא מפרסם כלום. פריימים נשלחים רק לחשבון Claude Code שכבר יש לך.

## 🤝 הוספת אפקט ב-5 דקות

מכיר טכניקה שחסרה? מוסיפים ערך אחד ל-`library/effects.json`, מריצים `./reel-effects index && ./reel-effects check` ופותחים PR. בדיקה אוטומטית מאמתת כל PR. הפירוט במדריך [CONTRIBUTING.md](CONTRIBUTING.md). אפקטים בלי תרגום לעברית מוצגים באנגלית, אז תרגומים הם תרומה ראשונה מצוינת.
